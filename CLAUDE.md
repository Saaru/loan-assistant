## Claude Code skills in this repo

- `/run-demo`: set up, start, verify and walk through the demo journeys
- `/tour`: guided architecture walkthrough with file references
- `/chaos-demo`: show how the assistant copes when a backend system slows down or fails
- `/add-action`: add a new customer-confirmed action (with OTP, idempotency and audit)
- `/add-workflow`: add a new use-case pack, e.g. collections or insurance
